# Laundry Wallah / Laundry Mart

A simple, static web page for **Laundry Wallah / Laundry Mart**, designed to introduce laundry services, display pricing, provide a booking form, and share contact details.

**Live Demo:** [https://divet1008.github.io/Laundry-Wallah-Laundry-Mart/](https://divet1008.github.io/Laundry-Wallah-Laundry-Mart/)

## Overview

The page presents a clean, straightforward layout tailored to a local laundry and garment-care business, highlighting quality service, customer satisfaction, and easy booking access.

## Sections & Features

- **Welcome & Introduction:** Introduces Laundry Wallah / Laundry Mart as a one-stop solution for laundry needs and includes a featured laundry image.
- **Our Services:** Lists core offerings such as:
  - Washing and Drying
  - Ironing and Folding
  - Dry Cleaning
  - Stain Removal
  - Express Services
  - Special Garment Care (and more)
- **Price List:** Displays transparent starting rates in a structured table (e.g., Washing and Drying at Rs 10.00 and Ironing and Folding at Rs 5.00).
- **Book Now:** Includes input fields for **Name**, **Email**, and **Phone** so visitors can initiate a booking.
- **Contact Information:** Provides a contact email (`info@laundrymart.com`) for inquiries.

## Getting Started

1. Clone or download the repository files to your local machine.
2. Open `index.html` in any web browser to view the page locally.

## Customization & Future Improvements

- **Pricing & Services:** Update the service list and price table to reflect current rates, units (per piece or per kg), and seasonal offers.
- **Booking Form Handling:** Connect the **Book Now** form to a backend service, form handler, or script so submissions are captured and confirmed.
- **Styling & Responsiveness:** Enhance visual styling, typography, and mobile responsiveness with CSS or a CSS framework.
